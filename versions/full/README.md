# Full version

Open `dist/index.html` directly, or serve `dist/` with any static host.

Edit `page.html`, `dist/styles.css` and `dist/app.js`. Rebuild with `python build.py` after installing the root `requirements.txt`. The build reads the bundled `../../reports/` directory; no original workstation or Hallmark installation is required.

From the repository root run `npm run verify:full` for the interaction checks. Install root development dependencies with `npm ci`; set `CHROME_PATH` if Chrome is installed elsewhere. Runtime uses no npm dependencies.

This layout is preserved from Site source commit `7702b4bed47dab8ddc7834fd6fe8a3760af950e6`. Research estimates scheduled class pressure, not actual passengers or available seats. Schedules were checked on 26 October 2026 for Winter 2026/27.
