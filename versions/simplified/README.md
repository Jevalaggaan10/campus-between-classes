# Simplified version

Open `dist/index.html` directly, or serve `dist/` with any static host.

Edit `page.html`, `dist/styles.css` and `dist/app.js`. Rebuild with `python build.py` after installing the root `requirements.txt`. The build reads the bundled `../../reports/` directory; no original workstation or Hallmark installation is required.

From the repository root run `npm run verify:simplified` for the interaction checks. Install root development dependencies with `npm ci`; set `CHROME_PATH` if Chrome is installed elsewhere. Runtime uses no npm dependencies.

This layout is preserved from Site source commit `967965e6ec301e569f99a9fc7e7841b126b61f20`. Research estimates scheduled class pressure, not actual passengers or available seats. Schedules were checked on 26 October 2026 for Winter 2026/27.
