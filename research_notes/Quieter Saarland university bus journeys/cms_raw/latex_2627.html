    Block Course "Introduction to LaTeX"

    From Wednesday, 6th of October, to Friday, 8th of October, the next iteration of this introductory course to LaTeX will take place. The course will be geared towards students of mathematics, but students from other faculties are welcome, too! Unfortunately, I can't award credit points or a certificate for the seminar. A (n incomprehensive) list of covered topics:

    • Basic mechanisms of LaTeX, crude typography, fonts and advice
    • Horses for courses: Document classes, presets and how to find existing material
    • Links, references, index
    • Bibliography using BibLaTeX and biber, sources for bibliographic information
    • Typesetting mathematics (general rules of thumb, nice to know environments and hacks from IEEEtrantools, mathtools, etc.)
    • Basic 2D sketches using TikZ, an overview over pgfplots, tikzcd
    • Setting up modular documents
    • Typesetting source code
    • LaTeX beamer
    • Letters

    The goal for this course is an overview over basic functionality, and a set of solutions for common tasks and problems. Learning LaTeX is like learning a language; you will not learn it properly without speaking it. To cover as much material as possible in the most efficient way, the course model will be slides. I know this is not ideal. For the first time, this iteration will include daily exercises.

    For an easy start, Overleaf can be used. A local installation is preferred for certain applications.

    If you want to join this course, please write an email to me so I can send out a student token or add you to the course manually.
